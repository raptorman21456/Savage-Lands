## Worth knowing before you redesign
- Level-up popup: the heading text runs into the first option.
- Pause > Settings: the SETTINGS heading is clipped at the top.
- The sandbox screens are the debug panel, not part of the player-facing game.
- Not captured: hover tooltips, button hover/pressed states, a fishing cast in progress, a race running, Church node tooltips.
